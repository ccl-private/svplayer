# svplayer
Secure Video Player

👉 [官方网站](https://ai-art.top)

Your private videos should stay on your own computer.
A local encrypted video player for private media. Offline by default. No media upload.

Core import, encryption, and playback stay free forever. Start free, upgrade later.

Two Usage Modes： Free first. Stronger with membership.
Free: one access code per library.
Member: one independent key per video.

Free Offline Mode
One library, one access code
All videos in that library share one access-control entry. Simple and ready to use.
Offline-first and free forever
Offline import, encryption, playback, and basic management stay free forever. No login needed to start.

Member Upgrade
Higher security
One independent key per video. A leak in one item does not weaken the whole library.
Less password burden
Access control is derived automatically. Less risk from weak, reused, forgotten, or poorly backed-up codes.
Faster organization
Custom tags are available in all modes. Upgrade to membership for fast tag filtering and retrieval.
